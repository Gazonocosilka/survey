# Room 21 — специфікація фурнітури

Сторінка-чекліст для постачальника (Dominus Build). Постачальник позначає позиції «Є в комплекті» / «Немає», лишає коментарі й підтверджує список. Відповіді зберігаються на сервері.

## Перегляд відповідей

`https://<ваш-домен>/answers`: підсумок (чого немає, коментарі, відповіді на питання, що додав постачальник, чи натиснуто підтвердження) і **Історія змін** з датою та часом кожної дії. Сторінка оновлюється сама кожні 30 секунд.

Щоб постачальник не міг її відкрити, задайте на Railway змінну `ADMIN_PASSWORD`. Браузер попросить логін і пароль: логін будь-який, пароль ваш.

## Запуск локально

```bash
npm start
```

Відкрити http://localhost:3000

## Railway

1. New Project → Deploy from GitHub repo → вибрати цей репозиторій. Railway сам запустить `npm start`.
2. Settings → Networking → Generate Domain — отримаєте публічне посилання.
3. **Щоб відповіді не зникали після редеплою:** додайте Volume (mount path `/data`) і змінну `DATA_DIR=/data`.

Без Volume сторінка працює, але збережені відповіді скидаються при кожному новому деплої.
